# Alpha13 release notes for homologation

This release candidate consolidates M5 recording/Studio corrections with media I/O and project portability intentionally pulled forward before M6.

User-visible additions:
- dedicated Share icon before Home;
- `Salvar e exportar` modal with editable project and final-master groups;
- portable `.guitarlab` save/open flow;
- import path expanded beyond WAV to planned V1 audio families;
- requested WAV Float32 / FLAC / MP3 master export paths;
- pencil/edit affordance for populated tracks.

This is not a general-public support declaration for every codec combination. The target Samsung physical checklist determines which new paths advance from implemented to Android-verified.
