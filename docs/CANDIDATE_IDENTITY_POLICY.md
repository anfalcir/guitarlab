# Candidate identity policy

The alpha13 signed deliverable must report:
- versionName `0.2.0-alpha13`;
- versionCode `14`;
- milestone `M5-final-physical-homologation-candidate`;
- gate `alpha13-awaiting-physical-validation`;
- the established M2 hardware baseline;
- the locked homologation certificate SHA-256.

Any mismatch blocks delivery.
